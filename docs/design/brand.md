# Brand

## Name

**My Dev Watch**. Three words, no camel case, no punctuation. The repository is
my-dev-watch; the Android package is io.github.smouj.mydevwatch.

## Mark

A single rounded watch case with the monogram MY inside. Two versions ship:

- assets/branding/logo-white.png — white monogram, transparent background, for dark
  surfaces and the README header.
- assets/branding/logo-color.png — navy case and teal monogram, for light surfaces.

The mark is never stretched, never placed on a busy photograph, and never recoloured
outside the palette below. Minimum size is 24 px; below that use the monogram alone.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Graphite | #0C1014 | App background |
| Surface | #151B21 | Cards, panels |
| Surface high | #1D252C | Inputs, selected rows |
| Off-white | #E9EDF2 | Primary text |
| Muted | #9AA5B1 | Secondary text |
| Teal | #2FB6C4 | Accent, active state, live values |
| Amber | #D79A3B | Research / unverified |
| Red | #D2564B | Errors and destructive actions |
| Green | #4FB477 | Stable / healthy |

One accent per screen. Teal means "this is live", amber means "we do not know yet",
and those two meanings must never be used decoratively.

## Typography

System stack (SF Pro on Apple, Segoe UI Variable on Windows, Roboto on Android).
No webfont: an offline app that renders a different face is a broken app. Numerals
are tabular in dashboards so values do not jump while syncing.

## Voice

Short, factual, no exclamation marks. "Battery 86 %" not "Battery level is looking
great!". When something is unknown, say unknown and link to the evidence.
